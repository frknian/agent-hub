# Roadmap

1. Current: authenticated project registration, persisted queued tasks, owner isolation, responsive dashboard, development seed, and installable PWA.
2. Future, requiring a separate brief: agent orchestration design, execution state transitions, durable work queues, review and approval flows.
3. Later: sandboxed execution, explicitly authorized repository access, usage accounting, operational monitoring.
   No later-phase functionality is implemented in Milestone 1.
